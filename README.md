# Learn Music Tutor Bureau Website

A responsive website demo for Learn Music Tutor Bureau in Varanasi.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production site is generated in `dist/`. Deploy that folder to any static hosting provider, then connect the owner's custom domain through that provider.

## Before publishing

This is an independently prepared demo, not an owner-approved official website. The business owner should verify all contact details, services, opening hours, reviews, and wording before publishing. Do not add pricing or claims without the owner's approval.
